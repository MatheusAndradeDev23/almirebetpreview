# Almir e Bete — Site Institucional

Site institucional desenvolvido para o salão Almir e Bete, com foco em apresentar o estabelecimento, divulgar seus serviços e facilitar o contato com clientes.

## Funcionalidades

- Página inicial personalizada.
- Apresentação dos serviços do salão.
- Galeria de imagens.
- Integração com WhatsApp para contato e agendamentos.
- Localização integrada ao Google Maps.
- Layout responsivo para dispositivos móveis e desktops.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

## Como executar localmente

1. Clone este repositório:

   ```bash
   git clone 
   ```

2. Entre na pasta do projeto:

   ```bash
   cd nome-da-pasta
   ```

3. Abra o arquivo `index.html` no navegador.
